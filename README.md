# kevin-stock

Kevin 的 A 股网页：**候选池 → 策略筛选 → 回测**。不做实盘下单。

## 做什么

1. **候选池（并集）**
   - 东财**行业板块**（一级行业，不含概念）：每个行业按**当日涨幅前 20** 取龙头。
   - 全 A 当日涨幅 **3%–8%**。
   - 两类都能进池，页面标明进池原因：龙头 / 涨幅区间 / 两者。
2. **策略**：条件表单（日K/周K、MA、MACD 柱），存在浏览器 `localStorage`。默认可买入要求两条都满足：周 MACD 柱（DIF−DEA，12/26/9）从近 26 周最低点拐头向上；日线 MA5 上穿 MA10。默认可卖出：周 MACD 柱处于近 26 周高点附近（≥90%）。
3. **筛选结果**：命中标的 + 命中原因。覆盖空/加载/失败状态。
4. **回测**：自选起止日。信号确认后**次日开盘**买卖；区间结束仍持仓按末日收盘结算。给出每只与合计（平均收益、胜率、交易次数）。

行情走服务端公开接口（东财行业/涨跌幅，腾讯/新浪 K 线），无 token。候选池与 K 线按日缓存。MACD/均线只计算候选池。

## 本地运行

```bash
npm install
npm run dev
```

开发服务默认 `http://127.0.0.1:4521`。

```bash
npm run build
npm start -- --port 4521
```

```bash
npm test
```

## 目录

- `app/page.tsx` — 主界面
- `app/api/pool` / `screen` / `backtest` — 候选池、筛选、回测
- `lib/market.ts` — 行情
- `lib/pool.ts` — 龙头 ∪ 涨幅
- `lib/indicators.ts` — MA、MACD
- `lib/strategies.ts` — 条件引擎
- `lib/backtest.ts` — 买卖回放

明确不做：实盘、登录/数据库、美股港股、概念板块全扫、公式语言。
